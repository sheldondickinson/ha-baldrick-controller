# Copy style: dry wit, wet-weather lights

Use original, understated, mildly self-deprecating British humour in introductions, empty states, documentation and non-critical hardware/footer copy. A pixel may be unruly; the operator is not the punchline.

Keep STOP, output status, faults, units, wiring and recovery instructions plain and specific. Never replace an actionable error with a joke. Do not copy vendor slogans, logos or long passages, and do not imply I Light That endorsement.

Examples: “Pixels organised. Tea optional.” / “A larger number is not a wiring diagram.” / “A map for pixels, which remain poor at directions.”

Technical claims and Australian spelling stay accurate. The joke gets one line; the instructions get the rest.
