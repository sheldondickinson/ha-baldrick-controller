A portable standalone tester and HA PixelTool destination. This installer uses original demo models.

Confirm the hardware first

Only the verified Waveshare ESP32-C6-LCD-1.47-M (SKU 30381), 8 MiB flash profile is covered. Chip detection does not prove your board's LCD wiring or flash capacity.

Disconnect external pixel power/data. Use a USB data cable. This is a fresh demo-model install: the merged image can erase existing settings, Wi-Fi and presets, and replaces built-in personal models with demos. Back up an existing device first.

This browser cannot use Web Serial here. Use a supported desktop browser over HTTPS or localhost.

After the flash

  1. Pixel output starts off. No SD or filesystem upload is needed.
  2. Use the fallback AP details shown on the LCD, then open http://192.168.4.1.
  3. Set your Wi-Fi details in Config and reopen the device at its LAN address.
  4. For HA output, pair the private access PIN on the companion server. Standalone tests remain independent.

No automatic Improv Wi-Fi setup is provided. For ordinary compatible-profile updates, use the private authenticated OTA helper rather than a fresh merged install.

What this demo includes

Finder, walk, ranges, strand cutter, patterns, saved presets and two synthetic reference grids. The HA companion can render supported uploaded models to the ESP; it does not copy that library into standalone firmware.

Independent community project. It is not an I Light That, Waveshare, xLights, ESPHome or Home Assistant product.
