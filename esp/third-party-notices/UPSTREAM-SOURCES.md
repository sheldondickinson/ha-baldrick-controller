# Upstream dependency sources

Pinned build dependencies remain under their upstream licences.

- Arduino-ESP32 3.3.12: https://github.com/espressif/arduino-esp32/tree/3.3.12
- ESP-IDF: https://github.com/espressif/esp-idf (version supplied by the pinned Arduino core)
- Adafruit NeoPixel 1.15.5: https://github.com/adafruit/Adafruit_NeoPixel/tree/1.15.5
- Adafruit GFX 1.12.6: https://github.com/adafruit/Adafruit-GFX-Library/tree/1.12.6
- Adafruit BusIO 1.17.4: https://github.com/adafruit/Adafruit_BusIO/tree/1.17.4
- Adafruit ST7735/ST7789 1.11.0: https://github.com/adafruit/Adafruit-ST7735-Library/tree/1.11.0

The accompanying demo source can be rebuilt with these dependencies; review their distribution terms before publication.
